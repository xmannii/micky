## میکی چیست؟

بیشتر برنامه‌های هوش مصنوعی دسکتاپ کم‌کم به محیط کاری بزرگی از پنل‌ها، رشته گفتگوها و کادرهای متن تبدیل می‌شوند. میکی کوچک می‌ماند. با گفتن **«هی میکی»**، زدن روی گوی یا استفاده از میانبر سراسری بیدارش کن. خواسته‌ات را بگو و یک جواب کوتاه فارسی بشنو.

پنجره اصلی یک همراه ۴۰۰ در ۷۱۲ پیکسلی است که دور یک گفتگو شکل گرفته. آرشیو جمع‌وجور گفتگوهای قبلی را نزدیک نگه می‌دارد، بدون اینکه برنامه همیشه شبیه یک پیام‌رسان باشد. پنجره شناور میانبر از هر برنامه‌ای باز می‌شود و هم صدا و هم تایپ را می‌پذیرد.

میکی در تمام چرخه فارسی‌محور است: متن رابط، عبارت بیدارباش، تبدیل گفتار محلی، دستورهای عامل و پاسخ صوتی. مدل زبانی انتخاب‌شده شاید زبان‌های دیگر را هم بفهمد، اما تجربه اصلی برای فارسی طراحی شده.

## سه بخش مستقل

میکی دستیار صوتی را به سه سیستم جدا تقسیم می‌کند. می‌توانی هر بخش را عوض یا خاموش کنی، بدون اینکه مجبور باشی دو بخش دیگر را تغییر بدهی.

| بخش            | کارش چیست                                                                          | انتخاب‌های تو                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 👂 **شنیدن**   | «هی میکی» را تشخیص می‌دهد، صدا را می‌گیرد و گفتار فارسی را به متن تبدیل می‌کند     | عبارت بیدارباش محلی ONNX، مدل‌های محلی [شنوا](https://huggingface.co/collections/Reza2kn/shenava-10-open-streaming-persian-asr-and-captioning)، میکروفن دلخواه و تنظیم زمان پایان جمله |
| 🧠 **مغز**     | درخواست را می‌فهمد، زمینه را نگه می‌دارد، ابزار انتخاب می‌کند و جواب کوتاه می‌سازد | OpenRouter، سرویس سازگار با OpenAI، Ollama یا LM Studio؛ شخصیت، حافظه، مهارت‌ها، ابزارها و جستجوی وب قابل تنظیم‌اند                                                                    |
| 🔊 **حرف‌زدن** | جواب میکی را با صدا می‌خواند                                                       | Gemini TTS، ElevenLabs یا حالت کاملاً خاموش برای پاسخ نوشتاری                                                                                                                          |

این جداسازی ترکیب‌های محلی و ابری را ساده می‌کند. می‌توانی شنیدن را محلی نگه داری، مغز را به OpenRouter بسپاری و صدای خروجی را خاموش کنی. یا مغز را با Ollama محلی اجرا کنی و یک صدای ابری داشته باشی. انتخاب هر سرویس در تنظیمات روشن و مستقل است.

## چرخه گفتگو

```text
«هی میکی»، گوی یا میانبر
          ↓
      شنیدن محلی
          ↓
    مدل انتخابی و ابزارها
          ↓
 جواب کوتاه و صدای اختیاری
          ↓
      شنیدن ادامه گفتگو
```

گفتگوی فعلی در فاصله بین پرسش‌ها و بعد از بارگذاری دوباره برنامه حفظ می‌شود. یک میانبر جدا هم برای شروع گفتگوی کاملاً تازه وجود دارد. پنجره شناور می‌تواند روی فقط صدا، فقط تایپ یا هر دو تنظیم شود. اگر در حالت هر دو شروع به نوشتن کنی، ادامه همان جلسه تایپی می‌ماند و میکروفن دوباره روشن نمی‌شود. برای جواب‌های بلند در دو مرحله بزرگ می‌شود و متن را قابل اسکرول و انتخاب نگه می‌دارد.

## میکی چه کارهایی انجام می‌دهد؟

- گفتگوی صوتی کوتاه فارسی با ادامه طبیعی مکالمه.
- دیکته در برنامه فعال، با پاک‌سازی اختیاری متن و چسباندن خودکار.
- جستجوی وب با سرویس انتخابی و خواندن صفحه‌های عمومی.
- دیدن نمایشگر فعال پس از درخواست مستقیم و نمایش توضیح روشن درباره ارسال تصویر.
- خواندن، جستجو، ساختن و ویرایش فایل‌ها در مسیرهای محافظت‌شده.
- بازکردن برنامه‌ها و اجرای دستورهایی که از سیاست امنیتی عبور کرده‌اند.
- نگه‌داشتن اطلاعات مفید و فایل‌های قابل ویرایش شخصیت، پروفایل و حافظه.
- ذخیره، جستجو، ادامه، خاموش‌کردن یا پاک‌کردن تاریخچه محلی گفتگوها.
- بارگذاری مهارت‌های سازگار فقط وقتی یک کار به آن‌ها نیاز دارد.
- بررسی نسخه‌های GitHub و پیشنهاد فایل نصب مناسب برای سیستم فعلی.

## حریم خصوصی و ایمنی

میکی اول از قابلیت‌های محلی استفاده می‌کند. فقط وقتی تمام سرویس‌های انتخابی محلی باشند، هیچ داده‌ای به سرویس ابری نمی‌رود.

| داده یا قابلیت      | کجا می‌رود؟                                                                                                 |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| صدای عبارت بیدارباش | با مدل‌های ONNX روی دستگاه پردازش می‌شود                                                                    |
| تبدیل گفتار         | با مدل دانلودشده شنوا روی دستگاه انجام می‌شود                                                               |
| تاریخچه گفتگو       | در SQLite محلی می‌ماند و می‌توان آن را خاموش یا پاک کرد                                                     |
| کلیدهای API         | در Keychain سیستم‌عامل ذخیره می‌شوند                                                                        |
| درخواست‌های عامل    | به سرویس مدل زبانی انتخابی می‌روند؛ Ollama و LM Studio می‌توانند محلی بمانند                                |
| پاسخ صوتی           | فقط هنگام فعال‌بودن سرویس مربوط به Gemini یا ElevenLabs فرستاده می‌شود                                      |
| تصویر صفحه          | بعد از درخواست مستقیم و توضیح روشن گرفته می‌شود و به مدل تصویری انتخابی می‌رود؛ میکی تصویر را ذخیره نمی‌کند |
| فایل‌ها و دستورها   | روی دستگاه و زیر کنترل مسیرهای مجاز، سیاست دستور، محیط محدود و تأیید کاربر اجرا می‌شوند                     |

در برنامه کد تحلیل رفتار یا تله‌متری وجود ندارد. برای خصوصی‌ترین حالت، شنوا را کنار Ollama یا LM Studio اجرا کن، صدای ابری را خاموش نگه دار و ابزارهای دسکتاپ را فقط هنگام نیاز روشن کن.

خواندن‌های معمولی و ویرایش فایل‌های متنی در مسیرهای مجاز می‌توانند مستقیم انجام شوند. فایل‌های اجرایی، مسیرهای شروع خودکار، دستورهای مخرب، نصب و کارهای حساس تأیید می‌خواهند یا مسدود می‌مانند. رمزها، داده مرورگر، کلیدهای SSH و مسیرهای حفاظت‌شده بیرون از دسترس ابزارها هستند.

## دانلود

آخرین فایل نصب را از [GitHub Releases](https://github.com/xmannii/micky/releases/latest) بگیر:

- **لینوکس x64 (اوبونتو و دبیان):** `micky-<version>-x64.deb`
- **لینوکس x64 (فایل قابل حمل AppImage):** `micky-<version>-x64.AppImage`
- **macOS برای Apple Silicon:** `micky-<version>-arm64.dmg`
- **Windows x64:** `micky-<version>-x64-setup.exe`

### نصب روی لینوکس (Ubuntu / Debian)

**با استفاده از بسته `.deb` (پیشنهادی):**
```bash
sudo apt install ./micky-<version>-x64.deb
```

**با استفاده از `.AppImage`:**
```bash
chmod +x micky-<version>-x64.AppImage
./micky-<version>-x64.AppImage
```

*نکته:* نگهداری امن کلیدها از GNOME Keyring یا KWallet استفاده می‌کند. برای چسباندن خودکار متن دیکته در برنامه‌ها روی نشست X11، بسته `xdotool` پیشنهاد می‌شود (`sudo apt install xdotool`).

نسخه‌های فعلی امضای دیجیتال ندارند و نسخه macOS هم notarize نشده است. ممکن است Gatekeeper یا SmartScreen هشدار نشان بدهد. میکی را فقط از همین مخزن دانلود کن یا خودت از کد منبع بساز.

## اولین اجرا

1. میکی را باز کن و اجازه میکروفن بده.
2. یکی از مدل‌های شنوا را دانلود کن. مدل کوچک‌تر سریع‌تر است و مدل بزرگ‌تر معمولاً دقت بیشتری دارد.
3. مغز را انتخاب کن: OpenRouter، یک سرویس سازگار، Ollama یا LM Studio.
4. اگر پاسخ صوتی می‌خواهی، Gemini یا ElevenLabs را تنظیم کن.
5. بگو «هی میکی»، روی گوی بزن یا میانبر سراسری را فشار بده.

مدل‌ها و سرویس‌ها ممکن است مجوز، سیاست حریم خصوصی و هزینه جدا داشته باشند. میکی دسترسی پولی هیچ سرویسی را همراه خودش ندارد.

## توسعه

### پیش‌نیازها

- Node.js نسخه 24.8 یا جدیدتر
- pnpm نسخه 9 یا جدیدتر
- macOS یا Windows برای خروجی‌های رسمی دسکتاپ

### اجرای محلی

```bash
git clone https://github.com/xmannii/micky.git
cd micky
pnpm install
pnpm dev
```

### بررسی تغییرات

```bash
pnpm typecheck
pnpm test
pnpm build
```

### ساخت فایل نصب

```bash
pnpm dist
```

فایل‌های نصب در پوشه `release/` ساخته می‌شوند.

## ساختار پروژه

| مسیر                     | مسئولیت                                               |
| ------------------------ | ----------------------------------------------------- |
| `src/`                   | رابط React، دریافت میکروفن، وضعیت‌ها، تنظیمات و آرشیو |
| `src/lib/`               | نوع‌ها و ثابت‌های مشترک میان پردازه‌های Electron      |
| `electron/conversation/` | ماشین حالت گفتگو و ادامه مکالمه                       |
| `electron/wake-word/`    | تشخیص محلی عبارت بیدارباش با ONNX                     |
| `electron/speech/`       | پردازه تبدیل گفتار محلی شنوا                          |
| `electron/agent/`        | چرخه ابزارهای مدل و قرارداد پاسخ فارسی                |
| `electron/system/`       | حفاظت مسیرها، سیاست نوشتن و دستورها و محیط محدود      |
| `electron/chats/`        | ذخیره محلی SQLite و جستجوی تمام‌متن                   |
| `electron/soul/`         | لایه‌های شخصیت، پروفایل کاربر و حافظه                 |
| `electron/llm/`          | سرویس‌های مدل و کلیدهای ذخیره‌شده در Keychain         |

رابط فقط از راه preload API با پردازه اصلی Electron حرف می‌زند. وضعیت گفتگو، درخواست مدل، ابزارها، مجوزها و ذخیره‌سازی در پردازه اصلی می‌مانند.

## انتشار و CI

هر push و pull request بررسی TypeScript و آزمون‌ها را اجرا می‌کند. تغییر نسخه روی شاخه `main` ساخت macOS، Windows و لینوکس را شروع می‌کند. بعد از موفقیت این خروجی‌ها، workflow برچسب `v<version>` را می‌سازد و فایل‌های نصب را به GitHub Release اضافه می‌کند.

برای آماده‌کردن نسخه بعدی:

1. مقدار `version` را در `package.json` تغییر بده.
2. فایل `CHANGELOG.md` را به‌روز کن.
3. تغییرات را commit و به `main` push کن.
4. ادامه آزمایش، ساخت، برچسب و انتشار را به workflow بسپار.

## مشارکت

گزارش خطا و pull request خوش‌آمد است. سیستم‌عامل، رفتار مورد انتظار، اتفاقی که افتاده و log مفید بدون اطلاعات محرمانه را بنویس.

میکی را کوچک، صوتی و فارسی‌محور نگه دار. ابزار و یک خط وضعیت را به داشبورد یا صفحه دائمی ترجیح بده. پیش از بازکردن pull request، `pnpm typecheck` و `pnpm test` را اجرا کن.

هیچ‌وقت کلید API، گفتگوی خصوصی، تصویر شخصی یا فایل مدل دانلودشده را در issue یا commit قرار نده.
